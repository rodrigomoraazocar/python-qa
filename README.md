# 🐍 python-qa

> Prática de **Python aplicado a Quality Assurance**: sintaxe, estruturas de dados, tratamento de exceções e ambientes virtuais, com exemplos voltados a testes de software.

---

## 🎯 Objetivo

Consolidar uma base sólida de Python para automação de testes — indo além da sintaxe pura, com foco em cenários reais de QA: parsing de respostas JSON, validação de dados e scripts de setup de ambiente.

## 🧰 Tecnologias e ferramentas

- **Python 3** — linguagem principal
- **venv** — isolamento de dependências por projeto
- **pip** — gerenciamento de pacotes

## ✅ Pré-requisitos

- Python 3.x instalado

```powershell
python --version
```

## 🚀 Como rodar

```powershell
python -m venv venv
venv\Scripts\activate
python nome_do_script.py
```

## 📚 Conceitos praticados

- 🔤 Variáveis e tipagem dinâmica
- 📦 Listas e dicionários
- 🔁 Controle de fluxo (`if` / `for` / `while`)
- 🧩 Funções e parâmetros com valor padrão
- ⚠️ Tratamento de exceções (`try` / `except`)
- 🧪 Ambientes virtuais e gerenciamento de dependências
- 📝 Scripts executáveis de ponta a ponta

## 📁 Estrutura

```
python-qa/
├── venv/            # ambiente virtual (não versionado)
├── meu_teste.py     # script de prática
└── README.md
```
